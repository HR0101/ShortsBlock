# YouTube Shorts Blocker

パソコンでもYoutubeShortsを見てしまう人用

## 概要
YouTubeのウェブ版（PCブラウザ版）から「ショート動画（YouTube Shorts）」を完全に非表示にするためのブラウザ拡張機能（Google Chrome / Microsoft Edge対応）です。
ショート動画の棚、サイドバーのリンク、関連動画からの導線などをすべてブロックします。

## 機能
- **CSSによる非表示**: ページ読み込み時に即座にショート関連要素を非表示にします。
- **JavaScriptによる監視**: ページ移動後など動的に追加されるショート動画要素も監視して削除します。
- **リダイレクト機能**: 万が一ショート動画のURL（`/shorts/...`）に直接アクセスした場合、自動で通常の動画プレイヤー（`/watch?v=...`）に切り替えます。

## プライバシーとセキュリティ（データ収集について）
この拡張機能は、ユーザーが安心して利用できるよう設計されています。
- **ユーザーデータの収集は一切行いません。**
- 閲覧履歴、検索履歴、YouTubeのアカウント情報などを外部のサーバーに送信することは一切ありません。
- 全ての処理（ショート動画の非表示化）は、お使いのブラウザ内だけで完結します。
